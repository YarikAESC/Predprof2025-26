Краткое описание проекта:
Система предназначена для автоматизации работы школьной столовой и организации безналичных расчетов. Платформа предоставляет пользователям различные роли: ученик (просмотр меню, отметка о получении питания, оплата, блюда в корзине, указание аллергий, отзывы), повар (учёт выданных завтраков и обедов, контроль остатков продуктов и готовых блюд, заявки на закупку продуктов), администратор (просмотр оплат и посещаемости, согласование заявок на закупки)

Ключевые возможности:
•  Онлайн-меню с выбором и предварительным заказом блюд.
•  Личный кабинет и виртуальный кошелек для каждого ученика.
• Администратор видит заказы и заявки на покупки, созданные поваром

Цель: Повысить эффективность работы столовой, обеспечить прозрачность расчетов и дать родителям инструмент для контроля питания детей.
Для развертывания проекта в среде должны быть установлены следующие библиотеки:Django,pillow,unittest ( или достаточно импортировать из Django.test);в терминале среды разработки, находясь в директории проекта, должна быть написана команда python manage.py runserver, а после чего ваш компьютер станет локальным сервером, на котором будет работать наше веб-приложение(доступ с других компьютеров в нашем проекте к сожалению не предусмотрен, и сайт развёртывается исключительно локально)


!!!Так-же важное уточнение по поводу организации абонемента - в нашем проекте эта функция реализована как комбо заказы, с возможностью указания количества повторения заказа, с оплатой всех таких повторений разом!!!
